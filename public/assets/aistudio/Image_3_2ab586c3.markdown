## Brand & Style

The design system establishes Dhanush T's digital presence as an advanced AI/ML Engineer and Full-Stack Architect. The aesthetic combines hyper-precise computational rigor with modern editorial finesse. It conveys high-leverage technical competence, architectural depth, and future-facing engineering capability.

The visual narrative blends **Dark Mode Precision**, **Refined Glassmorphism**, and **Terminal Cyber-Aesthetics**:
- **Atmospheric Depth:** Deep-space canvas layers with fine-mesh technical grid overlays and ambient radiant glows.
- **Luminescent Focal Points:** Electric purple and cyan luminous accents cutting through dark structural layers.
- **Tactile Instrumentation:** Semi-translucent glass panels, precision micro-borders with light refraction, monospaced computational tags, and timeline telemetry nodes.
- **Executive Engineering Poise:** Avoiding chaotic cyberpunk tropes in favor of restrained, surgical, high-density clarity suited for engineering leadership and high-tier client acquisition.

## Colors

The palette is engineered around an ultra-deep canvas, balanced by structural surface tiers and high-energy luminescent accents.

### Color Tiers & Roles
- **Canvas Base (`#0B0D12`):** Primary viewport backdrop, grounding the entire interface in near-black density.
- **Surface Elevation 1 (`#131620`):** Secondary container layer for layout panels, dashboard partitions, and structural wrappers.
- **Surface Elevation 2 (`#1A1E2E`):** Interactive card backgrounds, elevated dialogs, and terminal headers.
- **Primary Accent (`#8B5CF6` - Electric Purple):** System focus states, primary CTAs, active timeline checkpoints, and key narrative gradient anchors.
- **Secondary Accent (`#22D3EE` - Cyan):** Algorithmic badges, telemetry data visualizations, status indicators, and secondary highlights.
- **Tertiary Accent (`#6366F1` - Vibrant Indigo):** Supporting transitions, bridge gradients, and interactive hover shifts.
- **Text Primary (`#F8FAFC`):** Crisp high-contrast foreground text for paramount readability.
- **Text Muted (`#94A3B8`):** Body narratives, architectural descriptions, and technical metadata.
- **Border Subdued (`rgba(255, 255, 255, 0.08)`):** Foundational structural boundaries.
- **Border Active (`rgba(139, 92, 246, 0.4)`):** Highlighted card borders and interactive focus boundaries.

### Gradient Treatments
Headings leverage an inline linear gradient originating at `#FFFFFF`, transiting through `#C4B5FD`, and terminating in `#818CF8` at an angle of 135 degrees.

## Typography

The typographic hierarchy implements three specialized typefaces to balance personality, readability, and engineering pedigree:

1. **Headlines (`Space Grotesk`):** Provides a geometric, structural, modern-tech voice with distinct letterform quirks suited for titles, project cards, and metrics.
2. **Body (`Inter`):** Offers neutral, highly readable grotesque proportions optimized for long-form case studies, architecture briefs, and narrative clarity.
3. **Labels & Metadata (`JetBrains Mono`):** Grounds interface elements in code editors, command prompts, telemetry labels, and system status tags.

### Typographic Rules
- **Gradient Headings:** Display and XL headlines may utilize the primary-to-tertiary linear gradient fill via CSS text clipping (`background-clip: text`).
- **Monospace Metadata:** All tech stack tags, timestamps, commit hashes, and system states must strictly use `JetBrains Mono` with uppercase tracking (`letter-spacing: 0.05em`).
- **Line Heights:** Body copy line heights remain generous (1.5x minimum) to prevent optical clustering on high-contrast dark backgrounds.

## Layout & Spacing

The layout is built upon an adaptable 12-column fluid grid system bounded by a max container width of `1280px`.

### Grid Structure
- **Desktop (>= 1024px):** 12 columns, `1.5rem` (`24px`) gutters, `3rem` (`48px`) outer margins.
- **Tablet (768px - 1023px):** 8 columns, `1.5rem` (`24px`) gutters, `2rem` (`32px`) outer margins.
- **Mobile (<= 767px):** 4 columns, `1rem` (`16px`) gutters, `1.25rem` (`20px`) outer margins.

### Vertical Rhythm
A baseline spacing unit of `8px` governs section flows. Section separations scale between `80px` (mobile) and `120px` (desktop) to give high visual importance to individual projects and AI/ML experiments.

### Background Matrix Alignment
The canvas incorporates a technical CSS dot/grid overlay (`size: 32px 32px`, `opacity: 0.04`, color `#8B5CF6`) positioned strictly behind content containers to enforce systematic alignment without compromising textual legibility.

## Elevation & Depth

Visual hierarchy leverages physical translucency, layered surfaces, and chromatic illumination rather than generic drop shadows.

### Atmospheric Glassmorphic Layers
- **Surface Level 0 (Base):** Solid `#0B0D12`. Non-elevated regions.
- **Surface Level 1 (Card/Container):** Background `#131620` at `75%` opacity, paired with `backdrop-filter: blur(16px)` and a continuous perimeter stroke of `1px solid rgba(255, 255, 255, 0.07)`.
- **Surface Level 2 (Elevated Card/Modal):** Background `#1A1E2E` at `85%` opacity, paired with `backdrop-filter: blur(24px)` and a perimeter stroke of `1px solid rgba(139, 92, 246, 0.2)`.

### Chromatic Lighting & Aura
- **Resting State Elevation:** Cards receive an ambient dark occlusion shadow: `0 12px 32px -8px rgba(0, 0, 0, 0.6)`.
- **Hover/Active Glow:** Elevates elements using a dual-layer chromatic blur:
  `0 0 0 1px rgba(139, 92, 246, 0.4)`, combined with `0 16px 40px -10px rgba(139, 92, 246, 0.25)`.
- **Terminal Headers:** Solid `#1A1E2E` background with a subtle inner top highlight line: `inset 0 1px 0 0 rgba(255, 255, 255, 0.1)`.

## Shapes

The geometric signature balances friendly contemporary software aesthetics with modular software utility. 

- **Cards & Primary Modules:** Standardized to `rounded-2xl` (`1.5rem` / `24px`) to preserve a soft, contemporary silhouette that cradles glassmorphism diffusions smoothly.
- **Buttons & Chips:** Use a continuous curvature radius of `0.75rem` (`12px`) for buttons and `0.5rem` (`8px`) for compact computational badges.
- **Terminal Motifs:** Containers feature asymmetric styling: `1.5rem` rounded outer corners with a clean horizontal split separating terminal title bars from code outputs.
- **Timeline Nodes:** Perfect circles (`50%` radius) encapsulated by concentric micro-rings (`1px` width) pulsing outward.

## Components

### Buttons
- **Primary Action:** Solid background gradient from `#8B5CF6` to `#6366F1`, white text (`Inter`, medium 14px), padding `12px 24px`, radius `12px`. Hover initiates a cyan micro-glow and a `translate-y(-1px)` lift.
- **Secondary / Glass:** Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#F8FAFC`. Hover transitions border color to `#8B5CF6` and background to `rgba(139, 92, 246, 0.1)`.
- **Terminal Command Trigger:** Mono label with a `>` prompt prefix, subtle border, and integrated keyboard shortcut indicator (`Ctrl + K`).

### Chips & Developer Badges
- **Tech Stack Chips:** Background `rgba(19, 22, 32, 0.8)`, border `1px solid rgba(255, 255, 255, 0.08)`, font `JetBrains Mono` (12px), text `#94A3B8`.

### Project & Experiment Cards
